A simple storage plugin for WordPress.

== Description ==

Simple Storage is in early development. This release contains only the plugin skeleton: bootstrap, lifecycle hooks, and translation loading.

== Installation ==

1. Upload the `simple-storage` folder to `wp-content/plugins/`.
2. Activate Simple Storage on the Plugins screen.
